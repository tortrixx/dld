## 1. 游戏规则（对应课程要求 B1~B11）

| 关卡 | 目标图案 | 零片（`rtl/puzzle_pkg.vhd`） | 限时 |
|---|---|---|---|
| 第一关 | 图 4-1：4×3 实心矩形（12 格，矩阵行 2..5、列 2..4） | **3 块不同形状**：1×3 横条（3 格）+ 3-2-1 阶梯形（6 格）+ L 形三格块（3 格），面积 3+6+3 = 12 | 30 s |
| 第二关 | **固定「阶梯」PAT3**（16 格，**自拟**，B10） | **4 块异形**：1×3 横条(3) + 1×2 竖条(2) + J 形(5) + 六格块(6) = 16 格 | 40 s |
| **第三关** | **从四幅图案库随机选一幅**（田 / 十 / S·Z / 阶梯）—— 提高要求 A2「增加游戏关数 + 多种拼图图案随机选择」 | 同上（4 块异形） | 40 s（自拟） |

- 待机：点阵全灭、数码管显示「5____1」（B2）；
- 按【开始】→ 预览阶段：点阵显示完整目标图案并**从 5 倒数**，数码管同步（B4）；
- 对局：移动/选择/确认、零片散落、选中绿、锁定黄（B5~B9）；**零片还能 90° 旋转**（A4）；
- 全部锁定且**零片并集 == 目标图案** → 胜利；超时或"锁满但画面不对" → 失败（B9/B10）；
- 胜利 = 点阵**绿色粗对勾**、失败 = **红色叉**（"绿=通过 / 红=不通过"的交通灯配色）；
  结算画面**先闪 2 个 2 Hz 周期再常亮**，数码管最左四位拼 **PASS / FAIL**；
- **第二关图案固定**（PAT3「阶梯」，有 2 种等价铺法都算对）；**第三关图案每局随机**（A2）；
  第一关按 B4 固定为图 4-1；
- **关卡号显示在 DISP0（1/2/3）**；⚠️ **DISP2 在第二关对局时显示「2」是 B9 明文要求**（不是 bug），
  第一关与第三关对局时 DISP2 熄灭；
- 【开始】可随时重开一轮（对局中、失败后、胜利后，B11）；
- 拨动 SW7 到 0 → 立刻回到自检（8 位数码管全亮 8、2 Hz 闪）并清空状态（B1）。

按键（板子手册附图 26）：**开始** KEY14、**选择** KEY16、**上/下/左/右** KEY7/KEY15/KEY10/KEY12、
**确认** KEY11、⭐**【旋转】KEY8**（提高要求 A4：把选中的零片**原地**顺时针转 90°，位置不动；
会转出 8×8 或与别的零片相撞的请求**自动拒绝**，已确认的黄色块转不动）。
⭐ **第 14 工作阶段起旋转是通关必需的一步**：四块零片开局朝向是 `PIECE_ORI_INIT = 1/1/2/2`，
**不按【旋转】一定拼不出来**（`scripts/check_geometry.py` 穷举证明）。（KEY13 在本板上不可用。）

> ⭐ **`probe_nodes.py` 为什么存在**：`sim.py` 的 `OBSERVE` 是硬契约（名字不在网表里就报错），
> 但旧办法只有"把整个仿真跑完再看"（整机一轮 40~60 分钟）。
> 现在只需 `quartus_map`（~1 s）+ **100 µs 截断冒烟仿真**（<1 s）+ 读 `sim.rpt` 的**节点表**
> （仿真器自己列的全名，整机实测 41 823 条）⇒ **~2 秒**逐条判定。
> 用法：`python scripts/probe_nodes.py puzzle_top --reuse`（复用已有报告）、
> `--grep <正则>`（在节点表里找正确名字）。
>
> ⭐ **证据溯源**：每轮仿真记录（`sim/rounds/<模块>/rNN.json`）现在带 **`sources`** ——
> 全部 `rtl/*.vhd` 与本模块 tb 的 **git blob 哈希**，外加 `git_head` / `git_dirty`。
> 于是"这条绿证对应哪一版源码"是**可机检**的（`audit_evidence.py` 的 A 段），
> 不再靠人肉比时间戳（ERR-022 的陈旧绿）。
> 同理，`quartus/build_provenance.json`（**入库**）把"板上那份 `.pof`"与仓库 RTL 连起来
> —— 因为 `quartus/output_files/` 是 `.gitignore` 的，以前**没有任何机检手段**做这件事。

仿真用**压缩时钟**（`sim/tb_puzzle_top.py` 的 `RTL_PATCHES`：50 MHz → 80 kHz，随机源钉 0），
所以 96 ms 的仿真等价于板上的 60 s 对局；断言里的 ns 要按 **625 倍**换算成板上时间。
